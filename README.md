# Bean & Bite Bakery

## Project Description

Bean & Bite Bakery is a user-friendly bakery website showcasing artisan bread, seasonal pastries and specialty coffee. Customers can browse products, add multiple items to a shopping cart, checkout and receive an order confirmation.

## Features

* Home, About Us, Products, Gallery and Contact pages
* Product descriptions and prices
* Shopping cart with automatic totals
* Multiple products can be added to the cart
* Checkout page
* 10% new-member discount
* Order confirmation page
* Store collection option

## Technologies Used

* HTML
* CSS
* JavaScript

## Products

* Cappuccino

* Weekend Sourdough Box

Open `index.html` in a web browser to view and use the website.
